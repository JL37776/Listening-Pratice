# Listening Practice

A pure H5 listening practice tool. Users can create folders and projects, edit their own sentences, and use the browser Web Speech API to call system speech.

## Features

- Folder and project management
- Add, edit, and delete practice sentences
- Local browser storage
- Single, loop, and dictation modes
- Repeat count, speed, and system voice selection
- iPhone Safari system speech support

## Local Preview

Open `index.html` directly or serve the folder with any static server.

## GitHub Pages

The repository includes `.github/workflows/pages.yml`. Pushing to `main` deploys the root static files to GitHub Pages.
